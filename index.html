Akun baru mungkin perlu menyelesaikan verifikasi organisasi di dashboard OpenAI sebelum bisa memakai model gpt-image.

Stability AI

Stability API belum punya rasio 3:4 persis — 4:5 adalah pilihan potret terdekat.

Pollinations.ai

Provider gratis dan tanpa API key — cocok untuk mencoba alur kerja sebelum memasang key berbayar. Kualitas & konsistensi hasil lebih terbatas dibanding OpenAI/Stability.

Endpoint Kustom

Untuk platform AI image generate lain (Replicate, Leonardo, server sendiri, dll). Endpoint menerima POST JSON dengan placeholder {{prompt}}.

Contoh: jika respons {"data":[{"url":"..."}]}, isi data.0.url.

Tentang keamanan API key

API key disimpan hanya di browser ini (local storage) dan dikirim langsung dari browser ke API provider. Siapa pun yang memakai perangkat/browser ini bisa mengaksesnya. Jangan pakai pengaturan ini untuk website publik multi-pengguna — untuk produksi, sambungkan lewat backend/proxy milikmu sendiri agar key tidak terekspos di sisi klien.
